# Bilim Arena

Подготовка к ЕНТ в формате баттлов: дуэли 1×1 по ссылке, класс против класса, тренировка, рейтинг игроков, школ и городов, разбор ошибок.

- Node.js + Express + Socket.io, без сборки фронтенда.
- `npm install && npm start` → http://localhost:3000
- Если задан `DATABASE_URL` (Postgres), рейтинг хранится в базе; иначе — в `data/players.json`.
- Вопросы — в `questions.js` (поле `a` — индекс правильного ответа, `e` — объяснение).
